
## مقدمه برنامه‌نویسی موبایل با کاتلین و کامپوز

کاتلین زبان برنامه‌نویسی رسمی اندروید است که قدرت، سادگی و امنیت را به توسعه‌دهندگان ارائه می‌دهد. Jetpack Compose یک فریمورک مدرن برای توسعه رابط کاربری اندروید است که با کاتلین نوشته شده و طراحی UI را سریع‌تر و قابل فهم‌تر می‌کند.

***

## معرفی اندروید استودیو (Android Studio)

اندروید استودیو، محیط توسعه رسمی برنامه‌های اندروید است که توسط گوگل و JetBrains ساخته شده است. این IDE (محیط توسعه یکپارچه) ابزارهای لازم برای کدنویسی، طراحی رابط کاربری، تست و دیباگ برنامه‌ها را فراهم می‌کند.

### اجزای اصلی اندروید استودیو:

- **Editor (ویرایشگر کد):** جایی که کدهای Kotlin یا Java را می‌نویسید.
- **Layout Editor:** ابزار طراحی گرافیکی برای ساخت UI با کشیدن و رها کردن (در Compose بیشتر کد UI نوشته می‌شود).
- **Project Structure:** نمایش فایل‌ها و پوشه‌های پروژه.
- **Build System (مثل Gradle):** مدیریت ساخت، کامپایل و بسته‌بندی برنامه.
- **Emulator (شبیه‌ساز):** اجرای برنامه در محیط شبیه حقیقی گوشی روی کامپیوتر.
- **Logcat:** نمایش لاگ‌ها و خطاهای برنامه در هنگام اجرا.
- **Android SDK Manager:** ابزار مدیریت SDK‌ها و نسخه‌های اندروید.

***

## SDK چیست؟

SDK مخفف Software Development Kit است که مجموعه‌ای از ابزارها، کتابخانه‌ها و مستندات برای توسعه برنامه‌های Android را شامل می‌شود. 

مثلاً SDK شامل کامپایلرها، کتابخانه‌های پایه اندروید، ابزارهای توسعه، شبیه‌ساز و APIهایی برای تعامل با سخت‌افزار گوشی است.

اندروید استودیو با استفاده از SDK برنامه شما را می‌سازد و اجرا می‌کند.

***

## شبیه‌ساز (Emulator) چیست؟

شبیه‌ساز یک نرم‌افزار است که محیط یک دستگاه اندروید واقعی را روی کامپیوتر شما بازسازی می‌کند. 

این امکان را می‌دهد برنامه‌تان را بدون داشتن گوشی واقعی تست کنید، انواع اندازه صفحه، نسخه اندروید و قابلیت‌ها را شبیه‌سازی کنید.

شبیه‌ساز بخشی از Android SDK است و به راحتی از درون اندروید استودیو قابل اجرا و تنظیم است.

***

## شروع کار با پروژه در اندروید استودیو

1. **ایجاد پروژه جدید:** با انتخاب قالب Empty Compose Activity (برای Jetpack Compose) پروژه‌ای جدید ایجاد می‌کنید.
2. **ساختار پروژه:** پوشه‌ها مانند `src/main/java` برای کد Kotlin، `res` برای منابع (تصاویر، متن‌ها) و فایل `build.gradle` برای تنظیمات ساخت.
3. **نوشتن UI با Compose:** به جای XML، رابط کاربری را به صورت توابع Composable می‌نویسید که حالت و ظاهر UI را تعریف می‌کنند.
4. **اجرای برنامه:** با زدن دکمه Run برنامه روی شبیه‌ساز یا دستگاه متصل اجرا می‌شود.
5. **دیباگ و لاگ‌خوانی:** استفاده از Logcat برای مشاهده خطاها و اطلاعات برنامه.
